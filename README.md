One line, 116 characters: a software patch note for a bug in real life — the eyes spot a typo in someone else's message instantly, but ship three in your own. Written by a tiny deterministic Python program for make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty.

## Run it

```sh
python3 -P -s main.py
```

The program writes the patch note to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). It runs twice with byte-identical output and needs no network, no model call, and no secrets.
